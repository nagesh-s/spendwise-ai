Stack
- Language: Java
- UI: Views/XML + Material Components
- Navigation: Jetpack Navigation (NavHostFragment + NavController)
- Persistence: Room (Entities, DAOs, Database)
- Charts: MPAndroidChart (PieChart, BarChart)
- Calendar: MaterialCalendarView
- Import/Export: Storage Access Framework (ACTION_CREATE_DOCUMENT / ACTION_OPEN_DOCUMENT)
- Icons: Font Awesome TTF via res/font or assets

Version pins (example)
- Room: use latest stable from Jetpack release notes
- Navigation: use latest stable from Android Guide
- MPAndroidChart: com.github.PhilJay:MPAndroidChart:v3.1.0
- MaterialCalendarView: latest stable fork or prolificinteractive version
- Material Components: latest stable
